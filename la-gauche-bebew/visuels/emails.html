Emails La Gauche Bebew

Pour chaque email : A = l'objet, B = le corps. Après avoir collé : « Prévisualiser », puis « Enregistrer ». Si ça s'affiche mal : « Rétablir la valeur par défaut ».

1. Confirmation de commande

Paramètres > Notifications > Notifications clients > Confirmation de commande

A · Objet

Efface tout le champ « Objet de l'e-mail », colle.

B · Corps

« Modifier le code » → clique dans le code → Cmd + A (tout sélectionner) → Supprimer → colle.
