Emails aux couleurs de La Gauche Bebew

Tutoiement, ton direct, pas de prix chiffrés : rien à changer si les tarifs bougent.

1. Le style (une fois pour tous les emails)
  1. Paramètres > Notifications > Notifications clients > Personnaliser le modèle d'e-mail.
  2. Logo : logo-noir.png, largeur 300 px.
  3. Couleur : #111111. Enregistre.
2. Les textes (email par email)
  1. Clique sur l'email (ex. « Confirmation de commande »), puis « Modifier le code ».
  2. Objet : remplace tout le champ « Objet de l'e-mail ».
  3. Titre et texte : dans le code, cherche (Cmd/Ctrl + F) la phrase indiquée en gris et remplace uniquement ce texte. Ne touche jamais à ce qui est entre {{ }} ou {% %}.
  4. « Prévisualiser », puis « Enregistrer ». En cas de souci : « Rétablir la valeur par défaut ».
